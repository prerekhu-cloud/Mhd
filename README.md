# OpavaGO – zjednodušená verze

Nahrajte celou složku `opavago` do kořene repozitáře **prerekhu-cloud/Mhd**
(vedle souborů `26tr.glb`, `Irisbus.glb` …).

- `index.html` – aplikace (bez dat a obrázků, jen odkazy na ně)
- `data.js` – trasy, zastávky, jízdní řády a data pro hledání
- `img/` – náhledy vozidel a ikony

Aplikace pak poběží na https://prerekhu-cloud.github.io/Mhd/opavago/
